# Dabholkar Resort

A full static website for Dabholkar Resort, Konkan Coast.

## Pages
- `index.html` — Main resort website
- `admin.html` — Admin dashboard (login: admin / dabholkar2026)
- `nearby.html` — Nearby destinations page

## Tech
- Pure HTML / CSS / JavaScript (no build step)
- Supabase — booking storage & realtime updates
- Razorpay — advance payment collection

## Setup
1. Open `supabase_setup.sql` in your Supabase SQL Editor and run it once to create the bookings table.
2. Open `index.html` in a browser — no server needed.
